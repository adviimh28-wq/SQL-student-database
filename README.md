# Student Marks SQL Project

A beginner SQL project created to practice working with a student marks database.

## Student Data

| Name | Marks |
|------|------:|
| Anu | 90 |
| Ravi | 72 |
| Kajal | 80 |

## SQL Concepts Practiced

- Creating and inserting data
- Selecting and filtering data
- Sorting with `ORDER BY`
- Aggregate functions: `MAX`, `MIN`, `AVG`, `SUM`, `COUNT`
- `GROUP BY` and `HAVING`
- `UPDATE`, `DELETE`, and `ALTER TABLE` examples
- `DISTINCT`, `LIKE`, `IN`, and `BETWEEN`
- `AND`, `OR`, `IS NULL`, and `IS NOT NULL`
- String functions such as `UPPER`, `LOWER`, and `LENGTH`
- `CASE`, `COALESCE`, aliases, and `LIMIT`
